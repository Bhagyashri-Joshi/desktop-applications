# Digital Clock & Stopwatch

A lightweight desktop application built with **Java Swing** that combines a live digital clock and a precise stopwatch in one window. It has a clean, minimal interface, a horizontal navigation bar for switching pages, and a one-click light/dark theme toggle.

## Features

**General**
- Horizontal navigation bar to switch between pages
- Light and dark theme, switched instantly from the navigation bar
- Consistent, flat and minimal UI across both pages
- Resizable window with a minimum size
- Runs on Windows, macOS and Linux (cross-platform Swing look and feel)

**Digital Clock**
- Live time in 12-hour format with AM/PM
- Current date with the full weekday and month name
- Fixed-width digits so the display does not jitter every second

**Stopwatch**
- Start / Stop and Reset controls
- Millisecond precision (`HH:MM:SS.mmm`)
- Lap recording, newest lap first, showing the lap number, the total time and the split since the previous lap
- Lap button is enabled only while running; Reset only while stopped
- Timing is based on `System.nanoTime()`, so it stays accurate and is not affected by system clock changes

## Screens / Pages

| Page | Description |
|------|-------------|

## Architecture Overview

- **`Main`** sets the look and feel and opens `MainFrame` on the Swing event thread.
- **`MainFrame`** places the `NavBar` at the top and uses a `CardLayout` in the centre to show either `ClockPanel` or `StopwatchPanel`. It also holds the current `Theme`.
- **`NavBar`** reports page selections and theme toggle clicks back to `MainFrame` through callbacks.
- **`Theme`** is an enum with two palettes (`LIGHT`, `DARK`) and a helper to style buttons.
- **`Themeable`** is implemented by every component that needs to repaint itself when the theme changes. `MainFrame` calls `applyTheme(...)` on each of them.

## Installation & Setup

### Prerequisites

- **JDK 8 or newer** (JDK 17 or later recommended)
- Check that Java is installed:

```bash
java -version
javac -version
```

### 1. Get the project

Clone the repository or copy the project folder to your machine:

```bash
git clone <your-repository-url>
cd desktop-app-clock
```

### 2. Compile

Run this from the **project root** (the folder that contains `clockapp/`, not from inside it):

```bash
javac -d out clockapp/*.java
```

### 3. Run

```bash
java -cp out clockapp.Main
```

### Running from an IDE

1. Create a new Java project (IntelliJ IDEA, Eclipse, NetBeans or VS Code).
2. Add the `clockapp` folder as a source package.
3. Run `Main.java`.

### Optional: build a runnable JAR

```bash
javac -d out clockapp/*.java
jar cfe DigitalClock.jar clockapp.Main -C out .
java -jar DigitalClock.jar
```

## Usage

1. Launch the app. The **Digital Clock** page opens first.
2. Click the **Stopwatch** tab in the top bar to switch pages.
3. On the stopwatch, press **Start** to begin, **Lap** to record a lap, **Stop** to pause, and **Reset** to clear the time and laps.
4. Click **Dark mode** (or **Light mode**) at the top right to change the theme.

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `javac` is not recognised | Install a JDK and add its `bin` folder to your `PATH` |
| `error: Invalid filename: clockapp/*.java` | You are inside the `clockapp` folder. Go one level up and run the command again |
| `class, interface, enum, or record expected` | A file has extra or misplaced text. Each file must begin with `package clockapp;` |
| `Could not find or load main class` | Run `java -cp out clockapp.Main` from the project root after compiling |
